# قهوه پلاتو | Plato Coffee

سایت فروشگاهی مدرن برای فروش قهوه و تجهیزات مرتبط، الهام‌گرفته از طراحی حرفه‌ای فروشگاه‌های تخصصی قهوه.

## ویژگی‌ها

- طراحی کاملاً واکنش‌گرا (Responsive)
- پشتیبانی کامل از زبان فارسی و راست‌چین (RTL)
- فونت وزیرمتن (Vazirmatn)
- بخش‌های:
  - هیرو و معرفی برند
  - پیشنهادات ویژه محصولات
  - دسته‌بندی محصولات
  - مقالات و آموزش‌های قهوه
  - درباره ما و آمار
  - خبرنامه
  - فوتر کامل

## پیش‌نمایش

می‌توانید سایت را مستقیماً با باز کردن فایل `index.html` مشاهده کنید یا از GitHub Pages استفاده نمایید.

## تکنولوژی‌ها

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- JavaScript (Vanilla)
- Google Fonts (Vazirmatn)
- Font Awesome Icons
- تصاویر از Unsplash

## نحوه اجرا

فقط فایل `index.html` را در مرورگر باز کنید. نیازی به سرور یا build نیست.

## لایسنس

این پروژه صرفاً برای نمایش و تمرین ساخته شده است.
