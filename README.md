# قهوه پلاتو | Plato Coffee

سایت فروشگاهی چندصفحه‌ای مدرن برای فروش قهوه و تجهیزات.

## صفحات
- index.html — صفحه اصلی
- shop.html — فروشگاه
- about.html — درباره ما
- education.html — آموزش
- blog.html — وبلاگ
- contact.html — تماس با ما

## ویژگی‌ها
- جستجوی زنده (آیکون ذره‌بین)
- سبد خرید و علاقه‌مندی با localStorage
- کاملاً واکنش‌گرا و راست‌چین
- فونت وزیرمتن
